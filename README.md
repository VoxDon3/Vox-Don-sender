---​Vox Don Sender 🎮📲
​Vox Don Sender هو تطبيق أندرويد (APK) احترافي ومبتكر، تم تصميمه خصيصاً لمجتمع لاعبي ومعدلي أجهزة (PS4). يهدف التطبيق إلى تسهيل وتسريع عملية إرسال ملفات البيلود (Payloads) والأيقونات المخصصة إلى جهاز الألعاب عبر الشبكة المحلية (Wi-Fi) باستخدام بروتوكول FTP.
​يتميز التطبيق بواجهة مستخدم فريدة تعكس طابع "الجيمنج"، وتوفر تجربة غامرة مع الحفاظ على الأداء السريع والثبات.
​🚀 الميزات الأساسية (Key Features)
​واجهة مستخدم معدنية فريدة: تصميم داكن وجذاب مستوحى من أجهزة الألعاب، يحمل الهوية البصرية وشعار Vox Don.
​مكتبة أيقونات ضخمة: يحتوي التطبيق على معرض داخلي يضم أكثر من 55 أيقونة جاهزة ومصممة مسبقاً (أيقونات GoldHen الشهيرة) لتغيير مظهر الألعاب بضغطة زر.
​دعم الصور الخارجية: إمكانية تصفح واختيار أي صورة مخصصة من ذاكرة الهاتف الداخلية بصيغة PNG لإرسالها كأيقونة.
​معالج ومحول الصور الذكي: * واجهة مخصصة تقوم أوتوماتيكياً بقص الصور وتحجيمها لتتوافق مع المقاس القياسي المطلوب (512\times512 بكسل).
​تأثير بصري احترافي عبارة عن "وميض أخضر ناعم" حول العجلة المركزية ليدل على استمرار عملية المعالجة والتحويل دون تجميد الواجهة.
​إرسال ثنائي متزامن: يقوم التطبيق بدمج وإرسال ملف البيلود والأيقونة في أمر واحد لضمان السرعة واختصار الخطوات على المستخدم.
​إدارة الاتصال والشبكة: دعم كامل لإدخال عنوان الـ IP يدوياً، مع إمكانية تخصيص منافذ الـ Port الخاصة بالـ FTP والـ Payload بما يتوافق مع إعدادات جهازك.
​تنظيف الذاكرة المؤقتة: زر مخصص لتصفير البيانات ومسح الكاش (Cache) للحفاظ على خفة التطبيق وسرعته.
​🛠️ البناء التقني (Tech Stack)
​لغة البرمجة: Java
​تصميم الواجهات: Android XML
​الحد الأدنى للنظام المدعوم: Android 6.0 (Marshmallow) أو أعلى.
​البروتوكولات المستخدمة: TCP/IP Sockets & FTP.

​Vox Don Sender 🎮📲
​Vox Don Sender is a professional and innovative Android application (APK), designed specifically for the PS4 gaming and modding community. The app aims to simplify and accelerate the process of sending Payloads and custom icons to the gaming console over the local network (Wi-Fi) using the FTP protocol.
​The application features a unique user interface that reflects a true "gaming" aesthetic, providing an immersive experience while maintaining fast performance and stability.
​🚀 Key Features
​Unique Metallic UI: A dark, attractive design inspired by gaming consoles, featuring the visual identity and logo of Vox Don.
​Massive Icon Library: The app contains a built-in gallery with over 55 ready-made and pre-designed icons (including the famous GoldHen icons) to change the look of your games with a single click.
​External Image Support: The ability to browse and select any custom PNG image from your phone's internal storage to send as an icon.
​Smart Image Processor & Converter: * A dedicated interface that automatically crops and resizes images to match the standard required dimensions of 512 \times 512 pixels.
​A professional visual effect featuring a "soft green glow" around the central wheel to indicate that the processing and conversion are ongoing without freezing the interface.
​Simultaneous Dual Sending: The app merges and sends the payload file and the icon in a single command to ensure speed and reduce steps for the user.
​Connection & Network Management: Full support for entering the IP address manually, with the ability to customize the FTP and Payload ports to match your console's settings.
​Cache Cleaner: A dedicated button to reset data and clear the cache to keep the application lightweight and fast.
​🛠️ Tech Stack
​Programming Language: Java
​UI Design: Android XML
​Minimum Supported System: Android 6.0 (Marshmallow) or higher.
​Protocols Used: TCP/IP Sockets & FTP.
